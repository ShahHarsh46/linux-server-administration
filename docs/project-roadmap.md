# Project Roadmap

This roadmap tracks the practical work planned for the Linux Server Administration portfolio.

## Phase 1 — Storage administration (current)

- [ ] Inspect disks, partitions, filesystems, and mount points
- [ ] Create and verify partitions
- [ ] Create physical volumes and volume groups
- [ ] Create logical volumes and filesystems
- [ ] Configure persistent mounts using UUIDs
- [ ] Extend logical volumes and filesystems safely
- [ ] Record recovery and troubleshooting procedures

## Phase 2 — Accounts and permissions

- [ ] Create users and groups
- [ ] Configure supplementary group membership
- [ ] Set ownership and permissions
- [ ] Configure and verify ACLs
- [ ] Practice special permission bits

## Phase 3 — Services and networking

- [ ] Manage services with systemd
- [ ] Inspect logs with journalctl
- [ ] Configure network settings
- [ ] Verify DNS and network connectivity
- [ ] Diagnose service startup failures

## Phase 4 — Security and package management

- [ ] Inspect and manage SELinux modes and contexts
- [ ] Configure SELinux booleans where required
- [ ] Configure and verify firewalld rules
- [ ] Install and troubleshoot packages with DNF
- [ ] Configure and validate package repositories

## Phase 5 — Operations and reliability

- [ ] Configure cron jobs
- [ ] Build and test backup/restore procedures
- [ ] Perform system troubleshooting exercises
- [ ] Document evidence and lessons learned

## Completion rule

A checkbox is marked complete only after the task has been performed in the lab and its result has been verified. Screenshots or terminal output should be sanitized before publication.
